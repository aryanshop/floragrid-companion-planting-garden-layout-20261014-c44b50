# FloraGrid: Companion Planting & Garden Layout Planner

FloraGrid is an intuitive, visual garden layout planner designed to help gardeners optimize vegetable placement based on botanical companion planting rules. Placing beneficial plants side-by-side deters pests, improves soil nutrition, and maximizes yields, while avoiding antagonistic pairings.

## Features
- **Interactive Garden Grid:** Drag and drop or click-to-place vegetables and herbs onto a fully customizable grid.
- **Real-Time Synergy Analysis:** Instantly calculates neighborhood relationships, highlighting beneficial and conflicting pairs.
- **Synergy Score:** Rates overall garden health and harmony on the fly.
- **Crop Palette & Search:** Easily filter through common vegetables, herbs, and flowers with companion details.
- **Master Plan Exporter:** Generate a structured summary and layout map to copy and print for the growing season.

## Local Run Instructions
1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No installation, build steps, or internet connection required!

## Technical Note
This is a 100% static client-side project built using vanilla HTML5, CSS3, and modern JavaScript.
